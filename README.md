# ofree projects

This repository holds LaTeX projects written with ofree, an editor in the browser that
keeps your files in your own GitHub and builds your PDFs on your own GitHub Actions.

Each folder under `projects/` is one project. The PDF sits next to its sources; ofree's
own files are in the hidden `.ofree/` folders. Everything is plain files you can clone,
edit and build anywhere.

ofree adds its compile workflow, `.github/workflows/ofree.yml`, when you first open this
repository in ofree.
